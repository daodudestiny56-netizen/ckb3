# Workspace Rules: Auto-Push Changes

## Automatic Git Commit & Push
Whenever any code modifications, file creations, or edits are completed in this workspace:

1. **Stage all changes**:
   `git add .`

2. **Commit with a descriptive message**:
   `git commit -m "<brief description of the changes made>"`

3. **Push to Remote Repository**:
   Push the changes to `git@github.com:daodudestiny56-netizen/ckb3.git` on the active branch:
   `git push origin HEAD`
